# Craft.io

Craft.io is a product management platform with a REST API for managing product backlog, specifications, OKRs, roadmaps, and customer feedback across product teams. The public API provides enterprise customers programmatic access to workspace, portfolio, and feedback portal data, enabling integration with BI tools and organizational communication channels.

## APIs

- **Workspace API** — Access work items, custom fields, terminology, initiatives, products, epics, features, and stories
- **Portfolio API** — Access portfolio items, portfolio custom fields, and terminology
- **Feedback Portal API** — List portals and categories, retrieve feedback items, and submit new feedback

## Access

The public API is available to **Enterprise plan customers only**. Contact Craft.io Customer Success to request an API key. Three credentials are required:

1. Account API Key
2. Craft.io Account ID
3. Resource IDs (workspace, portfolio, or feedback portal)

## Endpoints

- US: `https://api.craft.io` — Swagger docs at `https://api.craft.io/docs`
- EU: `https://api-eu.craft.io` — Swagger docs at `https://api-eu.craft.io/docs`
